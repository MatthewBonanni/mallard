- Particle injector settings can be expressions of `x`, `y`, `z` and `t` (#1567): `rate` and `mass_flow` of `t` for pulsed or ramped injection, integrated within each step so the count over the run stays the integral to within a parcel; `velocity` (per component), `speed`, `direction`, `cone_angle`, `temperature`, `weight` and `diameter`, and each parameter of a size distribution, evaluated for each parcel where and when it enters, e.g. a nozzle's exit profile or a size that varies across an inlet. Numbers give the same particles, bit for bit, as before; an invalid value (a negative speed somewhere) stops the run, naming the injector, the key and the point.
