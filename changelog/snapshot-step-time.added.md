- Every snapshot records which snapshot it is: step, time (s), the run that wrote it (`run_id`, a UUID per run, and the run and step it restarted from), when and why it was written (`interval`, `start`, `end`, `stop`, `checkpoint`, `divergence`), its format version, the solver's precision, each field's units, description and stored precision, and for averaged fields the averaging window and sample count. It is a snapshot block in every format's own slot (VTU, PVTU and probe VTP comments, VTKHDF and XDMF HDF5 datasets, a restart trailer, the spectra CSV), next to field data `TIME` and `STEP` and the step in `.pvd`, `.vtkhdf.series` and XDMF indexes (#667).
- `mallard.jsonl` holds the run's output index: an `output` record (file, kind, step, time, reason, writer, run) for every file written, and the start record's `run_id` and `restart_of` (run log version 2). `--restart latest` finds the restart files through it (#667).
- Time-series CSV files (forces, integrals, probes, region reductions, spectra and the reactor's) mark where each run starts appending with its run block, and probe HDF5 files list each run with its first row (`mallard_runs`), so the reader gives every row its run. The reactor's CSV gains a `step` column and a units line (#667).
- `mallard info` prints the run block under **Run** (the same for every file of the run) and the last snapshot's block under **This snapshot**, with units, and each field's stored precision; `--format json` gives every snapshot's block and run (#667).
- Each snapshot block lists every field's stored precision (`float64`, `float32`) next to the solver's (#674).
