- `mallard check --view` in builds without HDF5 names each block's `.vtu` file so Windows accepts it: characters Windows forbids (as the quotes in `probes[name = "wake"]`) become `_`, device names such as `CON` get a leading `_`, and names that then coincide (ignoring case, as Windows does) get `~2`, `~3`, ...; the `.vtm` keeps each block's real name.
