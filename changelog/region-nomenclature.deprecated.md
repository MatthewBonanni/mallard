- `[[probes]]` `shape` is `type`, as in every region; `shape` is read with a warning until 0.10.0 (#499).
- Region types name one dimension each: `circle` and `ellipse` are curves; `disk`, `annulus`, `rectangle` and `polygon` are flat (areas in 2D, surfaces in 3D); `box` is a 3D solid. In `[[sources]]` regions, `type = "circle"` (a filled circle) is `"disk"` in 2D and `"sphere"` in 3D, `"ellipse"` is `"ellipsoid"`, `"box"` in 2D is `"rectangle"`, and in 3D `"disk"` is `"sphere"`, `"rectangle"` `"box"` and `"annulus"` a `"cylinder"` with `inner_radius` and `axis = [0, 0, 1]`. The old names are read with a warning that names the new one until 0.10.0, `mallard upgrade-input` rewrites them, and a region given them directly is an error that names the type to use (#499).
