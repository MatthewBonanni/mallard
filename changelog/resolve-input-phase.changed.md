- `mallard input resolve` and `mallard list keys input.toml` no longer read the mesh: every key is read and checked in the setup's input phase, so they take a fraction of a second on any mesh and work without the mesh file (a case whose resolve took 9 minutes now takes 0.14 s, with the same output). `mallard input resolve --format json` adds the numerics preset and the Preset row of `mallard check`. Errors only the mesh shows (zones, points outside the domain, fields registered with the mesh) are still found by `mallard check` and the run.
