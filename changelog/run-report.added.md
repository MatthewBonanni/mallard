- Every run writes `report.html` (`[output] report`, default on): one self-contained page of the run, built from its run record: the outcome, run identity, configuration, health (margins, activity, repairs, conservation, warnings), plots of the monitors, integrals and forces drawn in the browser (no network; at most 512 points per quantity, keeping each stretch's least and largest values), cost, the output index and the divergence report. Written at the first progress row, after each restart file and at the end, also of a run that stops, diverges or fails, and with `run_log = ""` too; `mallard info RUN_DIR --html` rebuilds the same page from `mallard.jsonl` (#515).
