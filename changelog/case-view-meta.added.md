- The case view's blocks carry their metadata: each block's kind (`mesh`, `boundary`, `cell_zone`, `region`, `probe`, `snapshot`, `periodic`), the key path it draws (`write_data[prefix = "out/near_wake"].region`), the input element that holds it with its index in its array of tables, and its zone, as field data in the ParaView file and in the new `view` of `mallard check --format json` and `mallard info MESH --view DIR --format json` (schema `mallard-case-view`, version 1), so scripts and the GUI no longer parse block names. `mallard check --view DIR --geometry-only` draws the same view without the numerics, the initial state or the run's checks: 15x faster on `examples/explosion_3d`, 4x on `examples/pulsed_jet` ([#1313](https://github.com/MatthewBonanni/mallard/issues/1313)).
