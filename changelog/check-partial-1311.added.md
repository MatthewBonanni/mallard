- `mallard list keys input.toml` answers for an input still being written: it lists the keys the setup read before it stopped, the required keys not set and the errors, and exits with 0 when the only errors are missing pieces (a required key or table, or a mesh file not there yet). `mallard check --partial` exits with 0 in the same case (#1311).
- `mallard check` reports the errors of independent parts of the setup together (`[run]`, the mesh, `[physics]`, each `[[boundaries]]` and `[[write_data]]` entry), and the warnings of the setup in its report. In `--format json` every diagnostic has `key` (`boundaries[1].T`), `line`, `column` and `missing` (#1312).
