- `[[particles.quantities]]` names are uppercase field names, like `RHO` and `U_X` (`[A-Z][A-Z0-9_]*`, none of the particle variables in any case): a lowercase name is an input error that names the line and the uppercase form, and `mallard input upgrade` rewrites the names and the expressions and `[[particles.probes]]` `fields` that read them. The particles `file` writes the velocity and temperature columns as `V_X`, `V_Y`, `V_Z` and `T_P`, as particle expressions read them, and particle probe files write `COUNT` and `MEAN_<field>`, `STD_<field>`, `MIN_<field>`, `MAX_<field>`.
