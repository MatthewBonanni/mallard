- Every output file is written as `NAME.partial` and gets its name once complete, as restart files already were: snapshots (each rank's piece too), their `.pvd`, `.vtkhdf.series` and `.xmf` indexes, XDMF data and mesh files, probe snapshots and spectra. A file under its own name is never cut short by a killed job; `mallard info`, `mallard diff` and `mallard post extract` refuse a `.partial` file and say its write did not finish, and `mallard info DIR` lists it (#669).
- The `output` records of `mallard.jsonl` are written once a snapshot is complete, also when written in the background, with `complete`, `bytes` and every file of the snapshot (each rank's piece too) with its size and SHA-256, hashed by one thread off the main thread, on the CPU's SHA instructions where it has them (ARMv8 SHA2, x86 SHA-NI). A snapshot without a record was not completely written (#669).
- `mallard info DIR` checks every file the run log records against its record: a missing file, or another size, is reported and exits 1; `--verify` also compares each file's SHA-256 (#669).
- The run summary's Writing line gives the time spent hashing the files for the run log, and how long the run waited for it when hashing fell behind writing (#669).
