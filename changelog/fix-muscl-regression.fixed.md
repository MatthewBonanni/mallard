- Time stepping, and so the throughput (cells per second, wall time per step) of progress rows, the run status, the summary and the run record, no longer counts the capture of step graphs in CUDA builds, a one-time cost of up to a few hundred ms that made short runs look slower than their steps are. The end record gives it as `wall_capture`, and the summary and the run page break it out.
- CUDA runs no longer load the device code of every source file at the first step graph's capture, which took 110 to 190 ms of an A100 run's startup (the chemistry, moving regions and TENO of runs that use none of them). The lock arrays of Kokkos's atomics are copied to every source file only when a capture fails.
