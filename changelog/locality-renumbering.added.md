- Each rank, and a serial run, can number its cells along a Hilbert curve for memory locality, so a mesh file's numbering no longer sets the speed of a run (a file numbered without locality was 2-6x slower on one GPU); results and output files are unchanged. `[mesh] cell_order = "auto"`, the default, counts the cache lines a block of cells reads over the reconstruction's stencil in both orders and takes the curve when it reads a tenth fewer (Gmsh's numbering of a sphere mesh: 11 times fewer, 1.5x faster on an A100; TENO on generated boxes: 3-7% faster; MUSCL on generated 3D boxes keeps their order); the run log's Mesh section says which. `"hilbert"` and `"input"` force either.
