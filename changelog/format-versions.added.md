- A documented compatibility promise for files: every release reads the restart and HDF5 mesh files of the earlier releases of its major version. Fixtures written by 0.6.0, 0.7.0 and 0.8.0 are tested. A file from a newer Mallard is rejected with a message that gives its format version and the versions this build reads. VTU output now carries its format version (field data `MALLARD_FORMAT_VERSION`), and `tools/mallard/vtu.py` and `tools/mallard/h5.py` refuse versions newer than they know (#331).
