- Boundary expressions read the boundary's local coordinates: the wall distance `n`, `xi` along the boundary from its center, and `eta`, `r`, `theta` (3D) or the arc length `s` (2D), so one profile (a boundary layer in `n`, a pipe profile in `r`) fits an inlet wherever it sits. `frame` and `walls` override the frame and the walls `n` measures from; the run log shows each entry's frame and coordinate ranges. A local variable of the same name (`var s := y`) hides a coordinate, so existing expressions keep their meaning (`examples/channel_inlet`, [#704](https://github.com/MatthewBonanni/mallard/issues/704)).
