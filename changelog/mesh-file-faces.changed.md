- CGNS, Fluent and OpenFOAM meshes are read by every rank of a distributed run together, as Gmsh files are: each rank reads a near-equal share of the nodes and of the elements (CGNS, by partial reads) or faces (Fluent, OpenFOAM, whose faces go to the ranks of their cells to rebuild them), so no rank holds the whole mesh. On 8M hexahedra, 3 ranks read a Fluent or OpenFOAM file in 12-14 s instead of 76-102 s, with a largest peak memory of 2.3 GB instead of 3.4-6.1 GB (rank 0), and a CGNS file in 1.4 s instead of 4.7 s (1.0 GB instead of 2.2 GB); one rank reads Fluent and OpenFOAM files about twice as fast. Meshes are bitwise unchanged and do not depend on the number of ranks (#1124, #1000).
- **ASCII Fluent and OpenFOAM files need one item per line, as Fluent and OpenFOAM write them:** ASCII Fluent node and face sections and ASCII OpenFOAM lists with several items on a line, or an item split over lines, are now an error naming the layout (OpenFOAM lists of up to 100 items may still be on one line). Export the file again if it was edited by hand (#1124).
