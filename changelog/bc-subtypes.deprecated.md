- **Boundary types renamed** to explicit subtypes, kind first (#564): `upt` is `inlet_state`, `p_out` is `outlet_pressure`, `p_out_average` is `outlet_pressure` with `average = true`, `extrapolation` is `outlet_extrapolation`, and `nscbc_inlet` / `nscbc_outlet` are `inlet_state` / `outlet_pressure` with an `nscbc` table holding their `L`, `sigma`, `beta`, `sigma_T` and `sigma_t`. The old names still run, with a warning, and give bitwise the same results; `mallard input upgrade` rewrites them. Removed in 0.10.0.
