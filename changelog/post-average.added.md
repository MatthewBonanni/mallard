- `mallard post average FILE...`: means, RMS, Reynolds and Favre covariances over saved restart files and snapshots, per cell as `[statistics]` keeps them (by its own code, bit for bit from restart files of the steps a run sampled), or over homogeneous directions as a CSV profile (`--homogeneous x,z`, with the dispersive part), the same bit for bit on any number of ranks and any `[mesh] cell_order`; `--statistics` averages a run's `[statistics]` snapshot over homogeneous directions, exactly as the profile of its states; `--region` restricts it; one state in memory at a time (#512).
- `[statistics]` `fields` and `products` take the derived fields (`MACH`, `P0`, `ENSTROPHY`, `MIXTURE_FRACTION`, ...), computed at each sample as `[[write_data]]` writes them (#512).
