- Snapshots of regions: `[[write_data]]` `region = ...` (or `regions = [...]`, a series per region) writes a filled region as the subset of cells it covers, with only their nodes and `REGION_FRACTION`; a boundary zone, the surfaces and curves of `[regions]` (one sample at each element of the region on the mesh) and probe types given as regions (`type = "cut_plane"`, `"line"`, `"points"`, ...) as the point values a `sampling = "point"` probe writes (cell fields from each sample's cell), in VTKHDF or VTK files, the same on any number of ranks; every region is written again at the end of the run. `[[probes]]` `region` also takes probe types as regions (#542).
