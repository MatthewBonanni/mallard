- The Python package's `File.read`, `read_all` and `geometry` return arrays that view the reader library's memory instead of copying it: a read peaks at the size of what it returns (one 183 MB vector field read from an 8M-cell VTKHDF file: 180 MB less peak memory) (#794).
- Reading the geometry of a VTKHDF file holds no second copy of its cells (8M hexahedra: peak 841 MB instead of 1.5 GB), and opening an XDMF series no longer reads its whole mesh topology at once (8M hexahedra: 231 MB instead of 655 MB); `mallard.open` and `mallard info` of large VTKHDF, XDMF and VTU files are 1.25-1.45x faster, from counting cell types by code (#794).
