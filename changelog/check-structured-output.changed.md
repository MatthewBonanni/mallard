- `mallard check` reports in sections whose headings end with their status, and in tables whose rows each start with one (`ok`, `WARN`, `ERROR`). Every number names its units, or says it is dimensionless or in wall units, and says what it is of (which rank, what state, against which limit). The result is on the first line and on the last. Boundaries are listed by zone with condition and faces, and the worst mesh cells by metric with their global ids. Errors and warnings are collected at the end, each with a stable code (`E-REGION-OUTSIDE`, `W-CFL-LIMIT`, ...) and the docs anchor that explains it. Running out of memory on the `--memory` target is now a warning (`W-SIZING-FIXED`, `W-SIZING-PARTS`). The report goes to stdout, warnings and errors included (#657).
- `mallard check --format json` prints the same report as one JSON object (`version` 1), for scripts and CI (#657).
