- `[[boundaries.data]]` reads boundary profiles from CSV tables and point clouds, in the format and with the keys of `[[initialize.data]]`, with `at` expressions of `x`, `y`, `z` and the local coordinates `u`, `v`, `n` and their twins in meters (`at = ["n_m"]` maps a boundary-layer profile in meters onto any wall-bounded inlet, `at = ["u"]` stretches a table from 0 to 1 across any inlet). The columns are variables `<name>_<column>` of the entry's expressions, read once per face at setup, so `u = "bl_u * (1 + 0.1 * sin(t))"` combines data and time on the device; the run log shows the data's range at the faces and the faces outside a table ([#1106](https://github.com/MatthewBonanni/mallard/issues/1106)).
