- **The 2D TENO setup runs on the device**, as the 3D one does: GPU runs set up their stencil tables there, one thread per cell, and CPU runs share the code (524,288 triangles at order 5, 2 threads: 44.9 s to 29.4 s). The device and the host give bitwise the same tables. **The tables change at round-off**: the order 5 and 6 smoothness-indicator matrices take their powers by multiplication, and arm64 Clang builds compute every 2D table without fused multiply-adds. TENO caches become `MALLARD-TENO-14`; older ones are recomputed (#776).
