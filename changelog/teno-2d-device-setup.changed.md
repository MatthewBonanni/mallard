- **The 2D TENO setup runs on the device**, as the 3D one does: GPU runs set up their stencil tables there, one thread per cell in batches of at most 16,384 cells, so the setup's workspace stays within the run's own peak, and CPU runs share the code. The device and the host give bitwise the same tables. On CPUs the setup is faster: 1.5 times from the shared code (524,288 triangles at order 5, 2 threads: 44.9 s to 29.4 s), then 1.7 times in 2D and 1.1 times in 3D at order 5 from fewer operations per table entry (#916). **The tables change at round-off**: the order 5 and 6 smoothness-indicator matrices take their powers by multiplication, and arm64 Clang builds compute every 2D table without fused multiply-adds. TENO caches become `MALLARD-TENO-14`; older ones are recomputed (#776, #938).
