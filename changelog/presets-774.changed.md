- **Changed default: the `les` numerics preset runs `SSPRK54` at `cfl = 2.0` instead of `SSPRK3` at 0.8. To reproduce earlier results, set `[numerics] time_integrator = "SSPRK3"` and `[run] cfl = 0.8`** (an input that already sets `cfl` or `dt` needs only `time_integrator`). The new default gives the same spectra on `cbc_les` and the same Taylor–Green decay for two thirds of the right-hand-side evaluations. `mallard input upgrade` notes the change for inputs with `preset = "les"` and no `time_integrator`, with the keys that input needs. The `high_order` preset keeps `SSPRK3`; the guide gives the comparison (#774).
