- **The `les` numerics preset runs `SSPRK54` at `cfl = 2.0`** instead of `SSPRK3` at 0.8: the same spectra on `cbc_les` and the same Taylor-Green decay for two thirds of the right-hand-side evaluations. To reproduce earlier results, set `[numerics] time_integrator = "SSPRK3"` and, if the input sets no `cfl`, `[run] cfl = 0.8`; `mallard input upgrade` notes the change for inputs with `preset = "les"` and no `time_integrator`. The `high_order` preset keeps `SSPRK3`; the numerics guide gives the comparison (#774).
