- The session's `initialize` (and `mallard version --format json`) gives `check`: the options `mallard check` takes and the GPUs `--memory` takes by name, with their memory. `case.view` takes `frames_only` to return the boundary frames without drawing or writing the view. `list keys INPUT` and `case.keys` give an optional table the input does not set its `type` and `form` from the general catalog. A request on a case that cannot be set up fails with its own error code, -32002, and the setup's diagnostics. See [Sessions](docs/guide/session.md).
