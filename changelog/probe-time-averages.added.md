- Probes read the `[statistics]` averages as variables (`MEAN_<A>`, `MEAN_U`, `COV_<A>_<B>`, `PHASE_<bin>_<A>`), each sample the value of its cell; and `average = true` writes the running time averages of a probe's own samples and reductions (`MEAN_<variable>`), for point values, fluxes and wall quantities, sampled on the `[statistics]` schedule, the same on any number of ranks and continued bitwise by restart files (#590).
