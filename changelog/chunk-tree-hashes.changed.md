- **The run log's output records identify files over 64 MiB by a chunk-tree hash** (`sha256_tree`, with `chunk_bytes` and the SHA-256 of each 64 MiB chunk in `chunks`) instead of their SHA-256, which every rank now computes in parallel, each hashing a share of the chunks of each file all ranks write (VTKHDF and XDMF snapshots, restart files), where rank 0 alone read back the whole file before: a 40 GB restart on 1000 ranks is hashed in the time of 40 MB. Any chunk of a copy verifies on its own, for resumable and parallel transfers. Files of one chunk keep their `sha256`; `mallard info --verify`, `mallard pack` and the run block's files read check either; the guide's [Complete files](docs/guide/output.md#complete-files) has a Python function that computes the tree hash ([#1329](https://github.com/MatthewBonanni/mallard/issues/1329)).
