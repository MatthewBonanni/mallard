- `mallard check --memory <GPU>` in a CPU build no longer counts the mesh's node coordinates and node lists in the steady state: GPU runs free them after setup, CPU builds keep them as the host copies (137 B per hexahedron, 66 B per tetrahedron for 3D TENO5). Where the steady state limits the cells per GPU, the CPU-predicted capacity was that much low; the GPU sizing now lists what it leaves out (#978).
