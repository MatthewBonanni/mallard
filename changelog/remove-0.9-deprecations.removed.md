- The input keys and options deprecated in 0.9.0 are removed: a run (and `mallard check`) with one stops with an error naming its replacement, and `mallard input upgrade old.toml > new.toml` still rewrites inputs of 0.8 and earlier. Removed: the `[[boundaries]]` types `upt`, `p_out`, `p_out_average`, `extrapolation`, `nscbc_inlet` and `nscbc_outlet` (use `inlet_state`, `outlet_pressure`, `outlet_pressure` with `average = true`, `outlet_extrapolation`, and `inlet_state` / `outlet_pressure` with an `nscbc` table), and the characteristic parameters `L`, `sigma`, `beta`, `sigma_T`, `sigma_t` outside the `nscbc` table; `[[mesh.curved]]` `shape` (use `type`, with `filled = false` for a sphere or cylinder); `[[write_data]]` `geometry` (use `region`, `"all"` being `"domain"`); `[mesh] periodic` and `[initialize.mesh] periodic` (use `[[periodic]]` and `[[initialize.periodic]]` zone pairs).
- `[[write_data]] format = "hdf5"`, the HDF5 solution files with XDMF indexes: use `"vtkhdf"`, which ParaView 5.12 and later open. `tools/mallard/h5.py` still reads the files of earlier releases; `[[probes]] format = "hdf5"` is unchanged.
