- The run block's `input.resolved` replaces the provenance's `setup` block (the terminal setup summary), and the preset values are the resolved input's TOML (`"\"HLLC\""`). The key catalog, the run block's preset and the log's preset line are made from the same key records as the resolved input (#509).
- Input tables are iterated in key order, not hash order: results no longer depend on the order of the keys in the file (e.g. the species of a composition `X = {...}`) or on the standard library. Runs whose input iterates a table, such as mixtures with a composition, change in the last bits (#509).
