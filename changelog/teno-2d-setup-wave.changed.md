- **2D TENO setup on NVIDIA GPUs**: a batch is one wave of the setup kernel's threads, as many as the GPU holds at once with the kernel's registers (41,472 cells on an A100, from 23,552 to 27,648), so the device tables take 14-37% less time on a 2.1M-triangle mesh (12.2 s instead of 19.3 s at order 6). The tables are bitwise the same, and the setup's workspace still does not grow with the mesh.
