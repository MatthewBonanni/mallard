- The run record's `end` record says how the run ended, as `outcome` (`finished`, `stopped`, `signal`, `wall_time_limit`, `diverged`, `error`) and `cause` (which stop condition, stop request or signal), with the last snapshot and restart file recorded complete (`step`, `t`, `path`) and the `reason` in words. It is also written when the run diverges or fails on rank 0, so a run without one was killed. `mallard info DIR` and the run summary state the outcome (#670).
