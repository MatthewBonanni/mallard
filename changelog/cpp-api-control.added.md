- C++ and Python API (#345): `on_progress`, `on_output` and `on_record` callbacks get each progress row, each output written and every run log record as structs (with their JSON), keeping the GPU's step queue and CUDA graphs; `set_log(sink)` sends the solver's console output to a callback (or nowhere) instead of stdout and stderr; `step(n)` takes n steps queued on the device, bit for bit as n single steps; `Case::set(key, value)` returns the case with one key set, changing only that key's line of its TOML, so code-built cases stay a TOML input that `mallard -i` reruns bit for bit, and `Case::save(path)` writes it for runs that build from the file. Guide: docs/guide/cpp_api.md, docs/guide/python.md.
