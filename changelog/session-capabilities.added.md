- `mallard version --format json` and the session's `initialize` answer the same `mallard-capabilities` object, now with the session's `methods`, `devices` (each GPU visible with its name and memory, the host's CPU and threads) and `control` (every key `mallard ctl set` takes with its type, units and element, and the routes `ctl` can take from where it runs). `mallard ctl set` checks keys and values against the table the run applies before sending.
