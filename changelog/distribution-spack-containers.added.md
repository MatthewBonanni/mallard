- Installation without compiling: container images for each release on `ghcr.io/matthewbonanni/mallard` (CPU for x86-64 and ARM; `:cuda` for NVIDIA A100 to H100), and a Spack package (`spack repo add --path spack/spack_repo/mallard https://github.com/MatthewBonanni/mallard.git`, then `spack install mallard`); `cmake --install` installs every executable, the examples, mechanisms and tools, and 2D and 3D builds install side by side (#328).
