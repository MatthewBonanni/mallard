- `Mallard upgrade-input old.toml > new.toml` brings an input from an older release up to date. It rewrites renamed, moved and removed keys and options and keeps comments and layout; `--check` exits 1 when a file is out of date. Renamed keys are deprecated first: they are still read, with a warning naming the new key, for at least one minor release before they are removed. The policy and the changed keys are in the user guide under "Inputs from older releases" (#332).
