- Output columns and monitored values are uppercase, like field names: `[integrals]` writes `KINETIC_ENERGY`, `ENSTROPHY`, ..., `LES_C`, `TF_BETA`; `[[forces]]` `F_X_PRESSURE`, ..., `F_Z_VISCOUS`; probe reductions `INTEGRAL_P`, `MEAN_P`, `FAVRE_`, `MIN_`, `MAX_`, `RMS_`, `MOMENT_<field>_<axis>` and the measure `COUNT`, `LENGTH`, `AREA` or `VOLUME`; probe samples `N_X`, `N_Y`, `N_Z` and `AREA` (HDF5 `NORMAL` and `AREA`, VTP and VTKHDF arrays `NORMAL` and `AREA`); `[statistics.convergence]` `STATIONARY`, `T_STATIONARY`, `CONVERGED` and `<signal>_MEAN`, `_CI`, `_VARIANCE`, `_VARIANCE_CI`, `_TAU`, `_N_EFF`, `_SAMPLES`; spectra peaks `F_PEAK_` and `ST_PEAK_`. Triggers and signals read them as `integrals_KINETIC_ENERGY`, `forces_<zone>_F_X_PRESSURE`, `<probe>_MEAN_P` and `convergence_CONVERGED`: a lowercase name is an input error that names the uppercase one, and `mallard input upgrade` rewrites them in `[[triggers]]` `when` and `do`, `[statistics.convergence]` `signals` and `[[probes]]` `spectra.fields`. Restart files that name convergence signals in lowercase still restore.
