- CUDA builds configured with a host compiler (e.g. `-DCMAKE_CXX_COMPILER=g++`, which Kokkos redirects to `nvcc_wrapper`) compile TENO with `--fmad=false` again, as builds with `nvcc_wrapper` as the compiler do, so tables set up on the device match those set up on the host bit for bit and TENO converges at its design order on one-cell-thick meshes. Configuring for CUDA with a compiler that does not reach `nvcc_wrapper` stops with a message naming the fix.
