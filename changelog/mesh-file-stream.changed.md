- Gmsh files are read by all ranks together: rank 0 finds where each rank's share of the nodes and elements lies in the file, and each rank parses only its share, so no rank holds the whole mesh. On 8M hexahedra at 3 ranks, the read takes 11 s instead of 95 s and peaks at 654 MB per rank instead of 1,465 MB on rank 0; serial runs read it 3 times faster at the same peak. Meshes are bitwise unchanged on any number of ranks (#1045).
