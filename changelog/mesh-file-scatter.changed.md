- Distributed runs on Gmsh, CGNS, Fluent and OpenFOAM meshes read the file on rank 0 alone, which sends each rank its block, instead of every rank reading the whole file; the file's cells are held as one array instead of one per cell. On 1M hexahedra from a Gmsh file, 3 ranks peak at 289 to 302 MB each instead of 339 to 347 MB, and a serial run at 615 B per cell instead of 681. Meshes are bitwise unchanged (#1000).
