- `[[write_data]]` VTKHDF output defaults to `series = true`: every snapshot goes into one file, `PREFIX.vtkhdf`, which ParaView opens as the time series, instead of `PREFIX_<n>.vtkhdf` files and their `PREFIX.vtkhdf.series` index. Set `series = false` for one file per snapshot, as before; `mallard input upgrade` notes each VTKHDF `[[write_data]]` without `series`. The Python readers take series files throughout: `mallard.vtu.read_index("solut/flow")` lists the snapshots of a series file, each a path that `read_vtu_cells` and the other readers read as that snapshot, `mallard.vtu.snapshot("solut/flow")` gives the last, and `mallard.vtu.read_pyvista` reads a snapshot of a series file with PyVista (`pyvista.read` reads its first). The example, tutorial and template scripts read series files; the Volvo bluff-body example keeps `series = false` for `volvo.py grid --follow --delete` (#768).
