- `mallard post extract FILE...` writes probes of existing output without rerunning: the input's `[[probes]]` (`--probe` chooses them), a region or probe type given with `--region` (points, curves, cut planes, surfaces with fluxes, region integrals, means and extremes), and with `--snapshot` snapshots of chosen fields and regions, on restart files, VTKHDF and XDMF snapshots and their series. The case comes from the file's run block (its relative mesh file, mechanism and TENO `cache_file` resolved from the run's directory) or `-i`; `--steps`, `--times`, `--every` and `--latest` choose the snapshots; the run's own probe code writes the files, so restart files give the run's probe values bit for bit, on any number of ranks. The report lists the files written and the last reductions with their units, or `--format json`.
