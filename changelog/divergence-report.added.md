- A run that diverges diagnoses the failure before it stops: the divergence report names the invalid cells (global ids, ranks, what failed first), the cell closest to failing and its neighbors in the last valid state (state, local CFL number, mesh quality, nearest boundary, repairs, TENO and limiter activity, chemistry sub-steps) and the last progress rows, and ranks the likely causes (time step, poor cells, a boundary condition, the initial state, chemistry, the scheme) with their evidence and what to try. It is printed, written to `divergence_report.txt` and `.json` (`[output] divergence_report`), added to the run record as a `divergence` record, and comes with a snapshot of the failure's neighborhood for ParaView; the error message names the most likely cause. Nothing is gathered while the run is healthy (#549).
