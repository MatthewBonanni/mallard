- `mallard check` without an input checks the environment, and `mallard check input.toml` ends with the same Environment section: the build and the solvers installed, Kokkos, every rank's host, device, CPUs and threads, MPI, GPU-aware MPI and NCCL (built, what the MPI library supports, whether the run uses them), HDF5 (serial or parallel), CGNS, zlib and KaMinPar, as text or `--format json`. Problems are diagnostics with their fix: `W-ENV-PLACEMENT` (the rank report's placement checks), `W-ENV-THREAD-BINDING`, `W-ENV-HOST-STAGING` and `E-ENV-GPU-AWARE-MPI`, which makes the exit status 1. Run it under `srun` or `mpirun` to check a job's ranks and nodes (#508).
- The run block's `build` gains `hdf5_parallel`: whether HDF5 was built with MPI (#508).
