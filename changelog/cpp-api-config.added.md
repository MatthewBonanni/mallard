- C++ and Python API (#345): typed configs generated from the key catalog, a class per table of the input with a typed, documented setter per key (`mallard/config.h`, `mallard.config`), which `Case::set(table)` writes into the case's TOML, so a typed case is still a TOML input that `mallard -i` reruns bit for bit; keys with a physical dimension take a `mallard::Quantity` (a number in SI units, or a value with its unit). `Case::set` appends an element to an array of tables at the index of its length. `Case::check()` gives `mallard check`'s report as structs (diagnostics, unused keys with suggestions, time step, resolution, memory, cost, the resolved input) and as its text and JSON. Guide: docs/guide/cpp_api.md#typed-configs, docs/guide/python.md.
