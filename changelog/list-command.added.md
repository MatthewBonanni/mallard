- `mallard list fields` lists every output field with its units, description, what a case needs to have it, and where it can be had: written by `[[write_data]]`, sampled by `[[probes]]`, averaged by `[statistics]` or derived after the run by `mallard post derive` (#502). `mallard list fields input.toml` reads the input and its mechanism, not the mesh, which need not exist yet, and lists exactly the fields its `[[write_data]] fields` accept, then the common ones it lacks and why (`MU_T: needs [les]`) (#786). `mallard list species input.toml` lists a case's species, and `mallard list templates` the case templates. The text is a table per group, with the units of every field (`dimensionless` where it has none); `list fields` and `list species` take `--format json` for scripts.
