- `mallard list fields` lists every output field with its units, description and what a case needs to have it; `mallard list fields input.toml` sets the case up as `mallard check` does and lists exactly the fields its `[[write_data]] variables` accept, then the common ones it lacks and why (`MU_T: needs [les]`). `mallard list species input.toml` lists a case's species, and `mallard list templates` the case templates. The text is a table per group, with the units of every field (`dimensionless` where it has none); `list fields` and `list species` take `--format json` for scripts.
