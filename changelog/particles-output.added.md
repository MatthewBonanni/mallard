- `[[write_data]] particle_fields`: particle snapshots at every write of the entry (interval, start, end, stop, checkpoint, trigger, divergence), the positions, ids and the listed particle variables and quantities of every particle, or of those in a volume `region`, as VTKHDF point clouds written asynchronously by every rank in parallel without gathering them; with `fields` too, one VTKHDF file holds the mesh and the particles as two blocks (ParaView 6.0 and later, `mallard check` warns with `W-PARAVIEW-VERSION`), and `particles = "separate"` writes `PREFIX_particles.vtkhdf` instead; the run record lists particle files as `output` records of kind `particles`, restarted runs continue their series, and `mallard info`, `diff` and the Python package read the mesh block of a combined file (#753).
