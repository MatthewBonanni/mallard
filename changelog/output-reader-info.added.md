- `mallard info FILE` reports what any file Mallard writes or reads holds, without an input file: kind, format version, mesh, times, fields with units and ranges, species and run block; for mesh files also their quality (`--mesh-fields PREFIX` writes it as fields). `mallard info RUN_DIR` lists a run's start, end and output files, `--input` prints the input that produced a file, and `--format json` prints any of it for scripts; the text is tables, with the units of every quantity in its column header or line. It reads every snapshot, series, restart, probe and CSV format, of any dimension and precision, through the one reader that the `mallard post` commands and the Python package share.
