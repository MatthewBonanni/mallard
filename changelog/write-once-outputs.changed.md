- **Output files are written once and never changed.** A VTKHDF series (`series = true`, the default, and every boundary, surface, curve and points snapshot) is now a file per snapshot, `PREFIX_<n>.vtkhdf`, with the mesh once in `PREFIX_mesh.vtkhdf` (linked from each snapshot); `PREFIX.vtkhdf` still opens in ParaView, h5py and Mallard as one file of every snapshot, now an index of HDF5 virtual datasets over the snapshots' files, rewritten after each one. Keep the files of a series together. A series written in one file by 0.11 or earlier is continued as `PREFIX_legacy.vtkhdf` plus new snapshot files. A rewind (resuming from an earlier restart file than the last) moves the files its writers wrote at the later steps to `.rewound/<run_id>/` before writing, and lists them in the run log's `start` record (`restart.superseded`), where `mallard info` finds them; a probe's HDF5 or VTKHDF file is copied there before the rewind cuts it back. An XDMF series continued from a restart keeps its mesh file rather than rewriting it. Every snapshot file of a series now has its SHA-256 in the run log ([#1326](https://github.com/MatthewBonanni/mallard/issues/1326)).
