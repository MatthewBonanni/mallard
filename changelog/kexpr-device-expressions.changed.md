- Every expression is evaluated by Mallard's compiled expression engine, with the same code on CPUs and GPUs: sponges (strength, state and composition), boundary `where` filters, mass-flow `profile`s and boundary compositions now evaluate on the device at setup. exprtk evaluated them with strength reduction, which rewrites some chains of divisions (`(a / b) / c` as `a / (b * c)`, ...); those now round as written, a difference in the last bits (none of the examples' expressions at these keys changes). Probe curves and surfaces and synthetic-inflow profiles keep their values bitwise ([Expressions](docs/guide/input_files.md#expressions)).
