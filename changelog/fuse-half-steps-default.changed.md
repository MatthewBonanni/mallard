- **Strang-split chemistry fuses each step's closing half step with the next step's opening one by default** (`[chemistry] fuse_half_steps = true`): one chemistry call per step. Output, checks, probes, statistics and triggers read the state with the pending half step applied, on a copy the run does not continue from, and restart files hold the state before it with its time (attribute `CHEMISTRY_PENDING`), so results no longer depend on the output schedule, and a run restarted at any step, or stopped by `t_wall_stop`, reproduces the uninterrupted one bitwise. Results change within the chemistry's tolerances; `fuse_half_steps = false` keeps the separate half steps, and `mallard input upgrade` notes inputs on the new default. On GPUs the steps with progress rows, monitors, means or probes of fused runs are taken one step at a time (#777).
