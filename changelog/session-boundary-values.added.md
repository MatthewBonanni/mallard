- `mallard check --boundary-values DIR` writes each `[[boundaries]]` entry's values at its faces as the boundary evaluates them (its keys, profiles and data files, with the local coordinates they read), and for `inlet_stagnation` and `inlet_mass_flow` the density, velocity and mass flux their flux makes of the initial state, marked estimated. The JSON report's `boundary_values` and the session's `case.boundary_values` give each file and each column's range. See [Boundary values](docs/guide/input_files.md#boundary-values).
