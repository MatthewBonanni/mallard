- C++ library API (#345): `mallard::Solver::field(name)` views a field of the rank's owned cells (conservative and primitive variables, partial densities, their blocks, `[statistics]` averages, cell centroids, volumes and global ids) in the solver's memory without a copy (device memory on GPUs; `Memory::host` for a host copy), described as DLPack does; `writable_field` and `commit_state()` set the state between steps, which the run log records as a `state_set` event; `on_step` and `on_stage` register callbacks after every step and at every stage of the time integrator, with no per-step host work while none is registered; `statistics()` gives the averaging window. Guide: docs/guide/cpp_api.md.
