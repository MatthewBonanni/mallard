- Probe files written by the host (moving region probes, and probes in runs that take one step at a time) and unaveraged spectra written at each sample copy their values from the GPU into pinned host memory, as snapshots and restart files do, instead of pageable memory. Files are the same bit for bit. (#373)
- Unaveraged spectra (`[statistics.spectra] average = false`) that the host writes itself (runs that take one step at a time) copy the spectra from the GPU once per file instead of once per value written: on one A100, `benchmarks/perf/air_3d.toml` with a file every 10 steps and `step_queue = 0` went from 3.2 s to 0.13 s per step.
