- `mallard completion bash|zsh|fish` prints a tab-completion script for the shell: commands, options, `latest` and restart files for `--restart`, input files, template names for `mallard new`, run directories and requests for `mallard ctl`. It is made from the command table that makes the help pages, so new commands complete as they are added. `cmake --install` (so Spack) installs the scripts under `share/bash-completion`, `share/zsh/site-functions` and `share/fish/vendor_completions.d`, and the containers load the bash one (#507).
