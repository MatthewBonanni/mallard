- `mallard pack RUN_DIR` writes one archive that reproduces a run, from its run record: the input as the run read it, the resolved input, the mesh file and every other file it read (each checked against the SHA-256 the run recorded), its start record and run record, and its small outputs (forces, integrals, probes; `--with-outputs all` adds snapshots and restart files), with a `manifest.json` of each file's size and SHA-256 and the command that reruns it. The archive is tar, gzip-compressed in builds with zlib. `mallard pack --verify ARCHIVE` checks every file against the manifest and the run block (#519).
