- Every command has a full help page: `mallard --help` lists the commands by purpose (run, set up, inspect, mesh, maintain), and `mallard <command> --help` (or `-h`, anywhere in the arguments) shows what it does, every option with its default, examples, the exit status and a link to the docs. The pages are collected in the user guide's [Command line](docs/guide/cli.md) page; `mallard mesh --help` and `mallard input --help` list their families (#503).
