- Running cases from Python (#345): `mallard.Case`, `mallard.Session` and `mallard.Solver` run a case in the Python process through the C++ API, with the same output and results bit for bit as `mallard -i`: stepping, monitors, fields as NumPy arrays of the solver's memory (on GPUs, `mallard.DeviceArray` through DLPack and `__cuda_array_interface__`, without copies), setting the state, and per-step and per-stage callbacks. They are an optional extension module of the package (`-DMallard_ENABLE_PYTHON_BINDINGS=ON`, nanobind), built in the containers and by Spack's `+python`; the rest of the package works without it. Guide: docs/guide/python.md#running-cases.
- C++ API: `mallard::Case::dimension()` tells a case's dimension as `mallard` does, and `mallard::Solver` refuses a case of the other dimension.
