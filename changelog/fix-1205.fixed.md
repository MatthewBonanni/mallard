- `[statistics.convergence]`: a sample that is not finite (NaN or infinite) no longer poisons a signal's prefix sums for the rest of the run, which made every later window NaN and MSER-5's start arbitrary. It is reported as a diverged run: the warning `W-CONVERGENCE-NONFINITE`, a count in the new value `<signal>_nonfinite`, and `converged` stays 0 from then on; the sample is kept out of the sums, so the other values stay finite (#1205).
