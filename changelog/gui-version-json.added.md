- `mallard version --format json`: the version, commit, build (dimension, precision, Kokkos backends, MPI, GPU-aware MPI, NCCL, HDF5, CGNS, zlib), dependencies, the dimensions of the solvers installed, and the schema name and version of every machine-readable interface, for programs such as a GUI to learn what a `mallard` supports (#1314). `mallard --version` is unchanged.
- The JSON of `mallard check --format json`, `mallard list keys --format json` and `mallard info RUN_DIR --format json` carries a `schema` field (`mallard-check`, `mallard-key-catalog`, `mallard-run-directory`) and a `version`; the run block's `build` gains `cgns` and `zlib` (#1314).
