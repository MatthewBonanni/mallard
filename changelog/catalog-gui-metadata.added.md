- The key catalog (`mallard list keys`, `mallard check --catalog`, `docs/input-keys/`) says which keys name files (`path`: input or output, file, directory or prefix, and the extensions taken), which name things defined elsewhere (`references`: regions, zones, boundaries, species, fields), the types of its table each key is read and required for (`for_types`, `required_for`, e.g. `initialize.file` only for restarts), and each table's mutually exclusive keys (`alternatives`, e.g. `dt` or `cfl`, `X` or `Y`). `mallard list species --format json` gives `molar_masses` (kg/kmol) ([#1399](https://github.com/MatthewBonanni/mallard/issues/1399)).
