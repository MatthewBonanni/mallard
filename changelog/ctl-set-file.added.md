- `mallard -i input.toml --set KEY=VALUE`: change a setting before the first step, through `mallard ctl set`'s keys and checks (a refused setting is an input error), e.g. `--set control_file_interval=10` to turn the control files on without editing the input; recorded as `set` events of `mallard.jsonl`, and repeated by `mallard pack`'s rerun command (#1316).
- A `SET` control file (lines of `key = value`) applies settings as `mallard ctl set` does, from anywhere the run directory is visible; refused settings are `W-SET-REFUSED` warnings of the run log. `control_file_interval` is now a setting `mallard ctl set` changes, and `set` events carry their `source` and `setting` (#1316).
