- C++ and Python API (#345): `Case::check()` gives the resolved input key by key (`CheckReport::keys`, `mallard.InputKey`): each key setup read with its value, whether the input sets it, and its record in the key catalog (type, physical dimension, unit, required, default, accepted values), as a GUI shows them beside each key. Every region of the typed configs is one class, `config::Region` (`config::Regions` in `[regions]`), with a setter for every key a region takes, wherever it is: `region` keys, the parts of booleans, lists of regions; Python's region lists mix regions and names. Guide: docs/guide/cpp_api.md#checking-a-case, docs/guide/cpp_api.md#typed-configs.
