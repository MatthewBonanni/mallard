- The provenance block is now the run block: schema `mallard-run` version 3, the XML comment `<!-- mallard-run {...} -->`, the HDF5 attribute `mallard_run` and the CSV line `# mallard-run {...}`, with `run.run_id` and `run.restart_of`. Files of earlier releases, with the old names, are read as before, with a note (#667).
- Restart files are written as version 7 (a snapshot block trailer before the run block's), which Mallard 0.9 and earlier reject with their newer-version message; every earlier version is still read (#667).
- Step, time and run come from what files record, never from file names: XDMF members from their data items, the mesh file of XDMF output from its attribute, `--restart latest` from the output index (a listing of `<prefix>_*.restart` ordered by what the files record for run logs before 0.10, said in its message), and `tools/mallard`'s `series()` in the order of the recorded time (#667).
- Spectra files record their step, time and averaging window in a snapshot block line in place of the free-text `# step = ...` line, and the divergence report names the run id (#667).
- File writes are `output` records of `mallard.jsonl` instead of `event` records (#667).
