- Keys with no default no longer stand for "off" or "automatic" with a magic value: leave them out instead. `[run] t_stop`, `t_wall_stop`, `n_steps` and `control_file_interval`, `[numerics.face_reconstruction] C_T`, `[particles] capacity` must be positive when given; `-1`, `0` or a negative value, which meant "no limit", "never" or "adaptive" before, is an input error that says to leave the key out. `[numerics.error_control] tolerance` must be positive, `[les.combustion] model` and `[statistics.phase] bins` are required, and `[output] write_stencils = ""` is an error (leave it out for no stencil file).
- The key catalog (`docs/input-keys/`, `mallard list keys`, `mallard check --catalog`) gives a key with no default `"unset"`, what leaving it out means (`"unset": "no wall-clock limit"`), in place of a sentinel default such as `-1.0` or `""`; `mallard list keys` shows it as `unset: no wall-clock limit`.
