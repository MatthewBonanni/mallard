- The scripts of `tools/post/` and the tutorials read Mallard's output through `mallard.open` (the solver's own reader) instead of the h5py readers, giving the same numbers; they need the library of a build with `-DMallard_ENABLE_PYTHON=ON` (the default), and the tutorials no longer need h5py. The Python package gains `mallard.series` (the snapshots of a series, or of the series and snapshot files of a directory, in time order) and `Geometry.triangles()` (a triangle fan of each 2D cell, for plotting) (#790).
