- A C++ library API (#345): `include/mallard/mallard.h` runs a case from a program, with `mallard::Case::from_toml_file` or `from_toml` and a `mallard::Solver` that sets it up, takes steps (`step()`, or `advance_to(t)`, landing on `t`), reports the time, step and latest integrals, forces and probe values, and ends the run, with the same output and results bit for bit as `mallard -i`. `cmake --install` installs it in `libmallard2d`/`libmallard3d` (`Mallard_ENABLE_LIBRARY`, on by default) with a CMake package: `find_package(Mallard COMPONENTS 2d)` and `Mallard::mallard2d`. Guide: docs/guide/cpp_api.md; example: `examples/cpp_api`.
