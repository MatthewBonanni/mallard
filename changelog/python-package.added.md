- The Python package `mallard` (`tools/mallard`, `pip install -e tools`): `mallard.open` reads every file Mallard writes or reads (VTKHDF, VTU, PVTU, XDMF output and their series indexes, region snapshots, restart files, probe CSV, HDF5 and VTKHDF files, forces, integrals and spectra tables, mesh files) into numpy arrays with their units, snapshots and run block, and `geometry()` their points and cells, through Mallard's own reader; `mallard.run_record` and `mallard.run_files` read a run directory; `mallard.info`, `mallard.diff`, `mallard.post.extract` and `mallard.post.convergence` run the commands and return their JSON. The reader is the library `libmallard2d`/`libmallard3d` of a build with `-DMallard_ENABLE_PYTHON=ON`; numpy is the only dependency. Guide: `docs/guide/python.md`; reference: `docs/guide/python_api.md` (#517).
