- Flamelet/progress-variable tables (#631, first stage of tabulated chemistry): `python tools/setup/flamelet_table.py table.toml` solves the S-curve of counterflow flamelets with Cantera, integrates it over a beta PDF of the mixture-fraction variance, and writes the table in Mallard's new versioned table format (`.mtab`, with its input and provenance in the header). The solver cannot run with these tables yet; see the [design notes](docs/design/flamelet.md).
