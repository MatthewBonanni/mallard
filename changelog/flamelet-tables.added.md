- Tabulated chemistry, first stage (#631): Mallard's table format for flamelet tables (HDF5, [specification](docs/design/table_format.md); float64 or float32 values, mapped from the file when its layout allows) and its reader, which checks a table against the contract of its model and thermodynamics tags (FPV with Saghafian's compressible thermodynamics first) and refuses unsupported tags by name. Reading tables needs a build with HDF5. Tables are written by a separate generator library, not by Mallard. The solver does not use these tables yet; see the [design notes](docs/design/flamelet.md).
